## Sobre

O beecrowd é uma plataforma de problemas de programação com correção automática: a solução só é aceita se produzir a saída certa para todos os casos de teste. Cada arquivo deste repositório leva o número do problema, para facilitar a consulta na plataforma.

## Exercícios

| Nº | Problema | Linguagem | Conceitos |
|---|---|---|---|
| 1117 | Validação de Nota | C++ | repetição, validação de entrada, formatação de saída |
| 1142 | PUM | C++ | laços com contador |
| 1151 | Fibonacci Fácil | C++ | sequências, variáveis auxiliares |
| 1234 | Sentença Dançante | C++ | manipulação de strings |
| 2542 | Iu-Di-Oh! | C++ | matrizes, funções |

## Como executar

Com um compilador de C++ instalado (por exemplo, o `g++`):

```bash
g++ "1142-PUM.cpp" -o pum
./pum
```

Depois, digite a entrada do problema no terminal.
